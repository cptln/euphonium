案例库

E/S/G Word

生成ESG报告章节初稿

给定上年报告结构和本年度数据要点，让AI产出某一披露章节（如气候风险应对）的初稿，供人工修订。

展开提示词
Prompt 
你是一名ESG报告撰写顾问。基于以下信息，撰写"气候风险应对"章节初稿：
1. 披露框架：[如ISSB/GRI/国内准则]
2. 本年度关键数据：[粘贴数据点，如碳排放量、能耗强度同比变化]
3. 上年度对应章节原文：[粘贴原文，作为行文风格参考]
4. 要求：
   - 语言正式、克制，避免营销化表述
   - 数据引用需与原文一致，不得推测或编造
   - 结构：现状→本年度举措→下一步计划
   - 字数控制在[X]字以内
输出后，请单独列出你使用了哪些数据点，方便我逐一核对。

要点：让AI在结尾列出引用的数据点，是核对事实性错误最省时的方法。

对标 Excel

同业ESG指标对标表

把多家同业公开报告中的ESG指标整理成统一口径的对比表，用于内部汇报或指标体系设计参考。

展开提示词
Prompt 
我将提供[N]家同业公司ESG报告中的指标原文片段。请帮我整理成统一格式的对标表：

列：公司名称 | 指标名称 | 原始数值 | 单位 | 统计口径说明 | 数据来源年度

要求：
- 如果不同公司口径不一致（如是否含范围3排放），在"统计口径说明"列明确标注差异，不要强行统一
- 无法从原文判断口径的，标注"口径不明"，不要推测
- 按指标类型分组排序：环境类→社会类→治理类

以下是原文片段：
[粘贴各公司报告原文片段]

要点：明确要求AI标注"口径不明"，避免它为了表格好看而悄悄统一口径。

体系 PPT

搭建ESG指标体系框架

从行业通用框架和公司实际情况出发，让AI辅助梳理一份可用于内部汇报的指标体系树状图大纲。

展开提示词
Prompt 
我需要为[行业]公司设计一套ESG指标体系，用于内部管理和对外披露。

背景：
- 参考框架：[如GRI/SASB/国内指引，可多选]
- 公司业务特点：[一两句话描述]
- 已有指标（如有）：[列出]

请输出：
1. 三级指标树（一级：E/S/G；二级：主题；三级：具体指标）
2. 每个三级指标标注：数据来源部门（建议）、更新频率（建议）
3. 标注哪些指标是"框架要求但公司目前缺失数据"的，单独列出

不要照抄框架原文，要结合我给的公司特点做取舍和归类。

要点：用于生成大纲/结构，实际数据缺口清单是后续工作分配的重要输出。

财务影响 Excel

ESG因素财务影响测算

把某项ESG风险或机会（如碳价上涨、供应链合规成本）转化为对财务模型关键假设的调整。

展开提示词
Prompt 
我正在评估[碳价上涨/供应链合规成本/具体ESG事项]对[公司名]财务预测的影响。

已知：
- 公司当前[相关成本/产量/排放量]数据：[粘贴]
- 情景假设：[如碳价从X涨到Y，时间跨度Z年]

请帮我：
1. 列出这个情景会影响利润表/现金流的哪些具体项目（如营业成本、资本开支）
2. 给出每个受影响项目的测算逻辑（公式形式，不要直接给最终数字）
3. 标注测算中依赖的关键假设，哪些是"行业普遍假设"，哪些是"需要我自己判断的假设"

目的是让我自己在Excel里搭建这个测算，不是要一个现成结论。

要点：让AI给逻辑和公式而非直接结论，分析师才能对假设负责、可解释给他人。

估值 Excel

ESG因素估值调整辅助判断

梳理某个ESG争议事件或趋势，是否、以及如何应该体现在估值模型的折现率或永续增长假设中。

展开提示词
Prompt 
请协助我思考以下ESG事项是否应反映在[公司名]的估值假设中：

事项：[如某项监管处罚/供应链丑闻/碳中和承诺]
当前估值模型关键假设：[如WACC=X%，永续增长率=Y%]

请分析：
1. 这类事项在同类案例中，通常通过调整哪个环节反映（折现率/现金流预测/终值假设），并说明理由
2. 列出支持"应该调整"和"不必调整"的论据，不要只给单一结论
3. 如果建议调整，给出合理的调整方向和幅度区间的参考逻辑（不是具体数字）

请保持中立分析的语气，最终判断由我来做。

要点：刻意要求正反论据并列，防止AI给出一个看似自信但未必稳健的单一结论。

投资分析 PPT

ESG投资分析要点PPT

把一份ESG研究笔记或数据梳理，转化为可以直接汇报用的投资分析要点页面结构。

展开提示词
Prompt 
请把以下ESG分析笔记，整理成一页投资汇报PPT的内容结构（不是完整PPT，是内容大纲）：

笔记内容：
[粘贴你的分析笔记/要点]

要求：
1. 标题：一句话结论（判断性语言，如"评级下调驱动因素"）
2. 三到四个支撑要点，每条不超过20字，要点前用一个动词开头
3. 单独列出"需要进一步验证的假设"，不要混在结论里
4. 语言风格：投研内部汇报口吻，克制、不夸张

要点：先出内容大纲再排版，比直接让AI"做一个PPT"效果更可控。
